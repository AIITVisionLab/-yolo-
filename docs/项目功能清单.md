# 项目功能清单

本文档基于当前仓库源码整理，目标是把这个项目已经具备的功能集中列出来，方便做交接、答辩、汇报或后续迭代规划。

## 1. 项目定位

这是一个面向植物病害识别与数据闭环管理的前后端一体化平台，覆盖了：

- 用户注册登录与权限控制
- 植物病害识别
- 识别结果可视化与智能建议
- 数据集创建、导入、下载、删除
- 图片标注与 YOLO 格式保存
- 数据增强与训练集/验证集重建
- YOLO 模型训练与训练任务跟踪
- 模型上传、切换、下载、删除
- 管理员后台的用户、模型、数据集、增强脚本管理

## 2. 系统角色

### 普通用户

- 注册账号、登录、退出登录
- 查看并使用自己可访问的模型
- 上传图片做病害识别
- 使用摄像头或屏幕共享做识别
- 创建和维护自己的数据集
- 标注图片、导入识别框、保存 YOLO 标注
- 发起数据增强和模型训练
- 上传、下载、删除自己的模型
- 使用公开模型和公开数据集

### 管理员

管理员除拥有普通用户能力外，还额外具备：

- 查看平台全部用户
- 封禁、标记、删除用户
- 上传平台级模型
- 切换当前在线模型
- 上传平台级数据集
- 管理增强脚本
- 切换当前启用的增强算法
- 查看和管理全平台模型、数据集、增强资源

## 3. 前端工作台功能

前端是一个基于 `Vue 3 + Vite` 的单页工作台，主要分为 4 个工作区。

### 3.1 病害识别工作区

#### 输入方式

- 本地图片上传识别
- 摄像头实时识别
- 屏幕共享识别
- 从视频流中手动截图后再做完整识别

#### 识别控制

- 选择当前推理模型
- 选择知识库数据集上下文
- 手动执行单次识别
- 开启/停止实时识别
- 调整置信度阈值
- 调整实时识别目标 FPS
- 选择实时识别策略档位
- 画中画功能

#### 识别结果展示

- 显示主预测类别
- 显示置信度
- 显示 Top 预测结果
- 显示所有检测框
- 支持框视图与热力图视图
- 显示预测耗时
- 显示 AI 建议生成耗时

#### 扩展能力

- 将识别结果送到标注工作区
- 把识别图像直接带入标注流程
- 导入识别框作为辅助标注结果
- 弹出独立识别小窗工作台
- 屏幕录制并下载录屏文件

### 3.2 标注与训练工作区

该工作区按数据集准备、标注、训练三个阶段组织。

#### 数据集管理

- 查看当前可访问数据集
- 创建新数据集
- 支持空白模板创建
- 支持按作物/病害模板创建
- 支持从现有数据集克隆创建
- 支持设置数据集公开/私有
- 支持导入本地 YOLO 数据集文件夹
- 支持批量上传原始图片到数据集
- 支持下载数据集 ZIP 包
- 支持删除数据集

#### 类别管理

- 查看数据集类别列表
- 新增类别
- 删除类别
- 按类别查看知识建议
- 为新类别后台生成 AI 知识建议
- 对数据集类别建议进行缓存复用

#### 标注能力

- 加载数据集原始图片
- 查看单张图片已有标注详情
- 画框标注
- 选中并编辑框的类别
- 删除单个标注框
- 清空当前图片全部标注框
- 保存为 YOLO 标注格式
- 支持保存新上传图片的标注
- 支持对已有数据集原图补充/修正标注
- 支持导入识别结果中的检测框
- 支持加载下一张未标注图片
- 支持专注标注模式（Focus Overlay）

#### 数据增强与训练

- 配置增强副本数量
- 配置训练集/验证集划分比例
- 配置随机种子
- 执行数据增强
- 重建 train/val 划分
- 选择基础模型训练
- 配置模型名称
- 配置 epoch
- 配置输入尺寸 imgsz
- 启动异步训练任务
- 轮询训练状态
- 展示训练结果摘要
- 训练完成后刷新可用模型列表

### 3.3 模型资产工作区

#### 模型列表

- 查看当前可访问模型
- 查看当前在线模型
- 区分公开/私有模型
- 区分官方/普通模型
- 显示模型归属人信息

#### 模型操作

- 上传个人 ONNX 模型
- 可同时上传标签文件
- 可同时上传元数据文件
- 上传后立即启用模型
- 设置模型为公开或私有
- 下载模型归档包
- 删除自己有权限管理的模型

#### 管理员专属

- 切换当前在线模型
- 查看接口文档入口
- 查看 OpenAPI Schema 入口
- 作为部署联调入口页使用

### 3.4 平台管理工作区

#### 用户管理

- 查看用户列表
- 查看用户数据集数量
- 查看用户模型数量
- 标记重点关注用户
- 封禁/解封用户
- 删除用户
- 删除用户时联动清理其资源

#### 模型资源管理

- 查看所有可管理模型
- 下载模型
- 切换当前模型
- 删除模型
- 上传平台模型

#### 数据集资源管理

- 查看所有可管理数据集
- 下载数据集
- 删除数据集
- 导入 ZIP 数据集
- 直接导入本地数据集文件夹

#### 增强脚本管理

- 上传增强脚本 `.py`
- 填写展示名、版本、作者、适用数据集类型、描述
- 上传后立即启用增强脚本
- 查看当前启用增强算法
- 快速切换已上传增强脚本
- 切回内置增强算法
- 删除自定义增强脚本

## 4. 后端 API 与业务能力

后端基于 `FastAPI`，按模块拆分为系统、认证、模型、标注、预测、管理几个路由组。

### 4.1 系统接口

- `GET /`
- `GET /health`

主要能力：

- 服务根接口
- 健康检查
- 返回当前系统状态
- 返回当前在线模型信息

### 4.2 认证接口

- `POST /auth/login`
- `POST /auth/register`
- `GET /auth/session`
- `POST /auth/logout`

主要能力：

- 用户注册
- 用户登录
- 会话恢复
- 退出登录
- 基于 `X-Auth-Token` 的会话认证

### 4.3 预测与 AI 建议接口

- `POST /predict`
- `POST /ai/recommendation`

主要能力：

- 上传图片进行 ONNX 推理
- 指定模型进行预测
- 指定置信度阈值
- 实时模式与普通模式区分
- 返回检测框、主类别、Top 预测结果
- 生成病害处理建议
- 按数据集上下文读取/写入知识库建议

### 4.4 模型接口

- `POST /models/upload`
- `GET /models`
- `GET /models/{model_name}/download`
- `POST /models/delete`
- `POST /models/select`
- `POST /models/train`
- `POST /models/train/tasks`
- `GET /models/train/tasks/{task_id}`

主要能力：

- 上传 ONNX 模型
- 上传模型标签和元数据
- 查询可访问模型
- 下载模型归档
- 删除模型
- 切换当前活动模型
- 同步训练
- 异步训练
- 查询训练任务状态

### 4.5 标注与数据集接口

- `GET /annotation/classes`
- `POST /annotation/datasets`
- `POST /annotation/datasets/import-folder`
- `GET /annotation/datasets/{dataset_name}/download`
- `POST /annotation/source-images/upload`
- `GET /annotation/source-images/{dataset_name}/{image_name}`
- `GET /annotation/source-images/{dataset_name}/{image_name}/detail`
- `POST /annotation/datasets/delete`
- `POST /annotation/classes`
- `POST /annotation/classes/delete`
- `POST /annotation/augment`
- `POST /annotation/save`

主要能力：

- 获取数据集与类别信息
- 创建数据集
- 导入本地文件夹形式的数据集
- 下载数据集
- 上传原始图片
- 下载原始图片
- 获取图片标注详情
- 删除数据集
- 新增类别
- 删除类别
- 数据增强和数据划分
- 保存 YOLO 标注

### 4.6 管理接口

- `GET /users`
- `POST /admin/users/{user_id}/disabled`
- `POST /admin/users/{user_id}/flagged`
- `DELETE /admin/users/{user_id}`

- `POST /admin/models/upload`
- `POST /admin/datasets/upload`
- `POST /admin/augmentations/upload`
- `POST /admin/augmentations/select`
- `DELETE /admin/augmentations/{script_name}`

主要能力：

- 获取平台用户列表
- 封禁/解封用户
- 标记/取消标记用户
- 删除用户
- 获取管理员总控数据
- 上传平台模型
- 上传平台数据集压缩包
- 上传增强脚本
- 切换增强脚本
- 删除增强脚本

## 5. AI 与知识库相关功能

这部分是项目里比较有特色的一层能力。

### 5.1 病害建议生成

- 根据识别结果生成中文建议
- 支持本地内置建议兜底
- 支持远端 OpenAI 兼容接口
- 支持多模态视觉模型分析图片
- 如果远端模型不支持看图，自动退回文本建议
- 如果远端模型不可用，自动退回本地建议

### 5.2 类别知识库

- 为标注类别生成长期缓存的知识建议
- 以“数据集 + 类别”为维度缓存
- 识别阶段可优先复用知识库中的建议
- 预测建议可回写进知识库
- 删除类别时同步删除知识条目

## 6. 模型推理与训练能力

### 6.1 推理能力

- 基于 ONNX Runtime 加载模型
- 自动缓存模型会话
- 支持多模型切换
- 自动读取模型标签文件
- 自动读取模型输入尺寸
- 支持硬件加速 Provider 优先级选择
- 使用 YOLO 风格预处理
- 执行 NMS 后处理
- 支持低阈值兜底，减少“完全无框”的情况

### 6.2 训练能力

- 基于 YOLO 训练脚本发起训练
- 支持设置基础模型
- 支持导出训练结果
- 训练结果写入 `training_runs`
- 支持异步训练任务状态管理

## 7. 资源与权限管理

- 用户与管理员角色区分
- 基于 token 的登录态校验
- 模型支持公开/私有
- 数据集支持公开/私有
- 资源归属到具体用户
- 管理员可跨用户查看和管理资源
- 普通用户只能操作自己有权限的资源

## 10. 项目当前可概括为的完整业务闭环

按使用流程看，这个项目已经形成了较完整的业务闭环：

1. 用户登录系统
2. 选择模型做病害识别
3. 获取识别框、类别和 AI 建议
4. 将识别图像送去标注
5. 创建或导入数据集
6. 补充类别与知识建议
7. 保存 YOLO 标注
8. 执行数据增强和训练集划分
9. 启动 YOLO 训练
10. 生成新模型并回到模型资产中心管理
11. 管理员统一维护用户、模型、数据集和增强脚本

## 11. 一句话总结

这个项目不是单一的“植物病害识别网页”，而是一个包含识别、标注、增强、训练、模型管理、知识建议和后台治理能力的植物病害 AI 工作台。
